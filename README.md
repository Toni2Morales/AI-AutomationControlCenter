# AI Automation Control Center## ObjetivoAI Automation Control Center es una aplicación web local pensada como proyecto de cartera técnica. Su objetivo es demostrar la integración de automatización, inteligencia artificial local, tratamiento de datos, APIs, bases de datos y auditoría en un entorno reproducible y completamente local.## Problema que resuelvePermite automatizar flujos de trabajo que combinen extracción, validación y procesamiento de datos con modelos de IA locales, sin depender de servicios de pago ni de claves de API externas para la funcionalidad principal.## Funcionalidades### Previstas (no implementadas)- Extracción y validación de facturas con IA local mediante Ollama.- Limpieza y normalización de datos con Pandas.- Orquestación de flujos con n8n autoalojado.- Interfaz web con Angular para consulta de ejecuciones y auditoría.- API REST con FastAPI.- Almacenamiento persistente en PostgreSQL con trazabilidad.- Migraciones con Alembic.- Validación estricta de las salidas del modelo contra esquemas explícitos.- Evaluación de prompts con casos deterministas.- Pruebas automatizadas con pytest.- Colección de API para pruebas con Postman.### Implementadas- Estructura base del repositorio y documentación inicial.## Arquitectura y tecnologías- **Frontend:** Angular con TypeScript en modo estricto- **Backend:** FastAPI (Python 3.12)- **Base de datos:** PostgreSQL- **Automatización:** n8n autoalojado- **IA local:** Ollama (modelo configurable, previsto qwen2.5:3b-instruct)- **Migraciones:** Alembic- **ORM:** SQLAlchemy- **Validación:** Pydantic- **Datos:** Pandas- **Pruebas:** pytest- **API testing:** Postman- **Orquestación:** Docker Compose- **Control de versiones:** Git y GitHubConsulta docs/arquitectura.md para más detalles sobre componentes, comunicaciones y límites de seguridad.## Requisitos previos- Git- Docker Desktop con contenedores Linux- Node.js y npm- Python 3.12 (objetivo).
